# بیلد رسمی تلگرام دسکتاپ با حساب‌های نامحدود 🖥️

این ریپو فقط یک چیز انجام می‌دهد: **تلگرام دسکتاپِ رسمی** (شاخهٔ `dev` از `telegramdesktop/tdesktop`) را با **یک وصلهٔ بسیار کوچک** بیلد می‌کند تا محدودیتِ ۳ حساب کاربری برداشته شود و بتوانید حساب‌های **نامحدود** (عملاً تا ۱۰۰۰) اضافه کنید.

بقیهٔ چیزها **دقیقاً همان تلگرام رسمی** است: همان رابط کاربری، همان ورود با شمارهٔ تلفن + کد تأیید، بدون نیاز به وارد کردن api_id/api_hash توسط کاربر.

---

## 🔧 وصله چه می‌کند؟

فقط یک فایل تغییر می‌کند: `Telegram/SourceFiles/main/main_domain.h`

| ثابت | مقدار اصلی | مقدار جدید |
|---|---|---|
| `kMaxAccounts` | `3` | `999` |
| `kPremiumMaxAccounts` | `6` | `1000` |

همهٔ نقاط دیگر برنامه (دکمهٔ «Add Account»، چکِ ذخیره‌سازی، کادر محدودیت، ...) از همین دو ثابت استفاده می‌کنند، بنابراین با این تغییر کوچک کل محدودیت برداشته می‌شود. متن کامل وصله در [`patches/unlimited-accounts.patch`](patches/unlimited-accounts.patch) هست.

## 🚀 نحوهٔ استفاده

1. این ریپو را به حساب GitHub خودتان Fork یا Import کنید.
2. بیلد در دو حالت اجرا می‌شود:
   - **خودکار:** پوش‌کردن یک تگ با الگوی `v*` (مثلاً `git tag v1.0 && git push origin v1.0`)
   - **دستی:** از تب **Actions** → انتخاب ورک‌فلو `Build Windows` → دکمهٔ **Run workflow**
3. پس از پایان بیلد، خروجی زیر صفحهٔ اجرای ورک‌فلو (بخش **Artifacts**) ظاهر می‌شود:
   - `windows-exe` → فایل زیپ شامل `Telegram.exe` (و `Updater.exe`)
4. زیپ را باز کنید، `Telegram.exe` را اجرا کنید — نیازی به نصب ندارد (نسخهٔ پرتابل).

> ⚠️ **اجرای اول بیلد طولانی است** (آماده‌سازی کتابخانه‌ها چند ساعت طول می‌کشد). کش‌ها ذخیره می‌شوند و بیلدهای بعدی خیلی سریع‌تر خواهند بود. اگر جاب اول به خاطر محدودیت زمانی قطع شد، فقط دوباره اجرایش کنید؛ کشِ مرحله‌به‌مرحله ذخیره می‌شود و ادامهٔ کار از همان‌جا شروع می‌شود.

## 🔐 دربارهٔ api_id / api_hash

در نسخه‌های اخیر تلگرام دسکتاپ، اعتبارنامهٔ API دیگر داخل سورس ثابت نیست و باید هنگام configure از طریق `-D TDESKTOP_API_ID` و `-D TDESKTOP_API_HASH` داده شود. این ورک‌فلو به‌صورت پیش‌فرض از اعتبارنامهٔ عمومیِ خود کلاینت رسمی Telegram Desktop استفاده می‌کند (بنابراین کاربر هیچ چیزی وارد نمی‌کند و ورود دقیقاً مثل تلگرام رسمی است). اگر خواستید اعتبارنامهٔ خودتان را بگذارید، دو Secret با نام‌های `TDESKTOP_API_ID` و `TDESKTOP_API_HASH` در تنظیمات ریپو بسازید.

توجه: استفاده از اعتبارنامهٔ رسمی در کلاینتِ ویرایش‌شده از نظر شرایط استفادهٔ تلگرام خاکستری است؛ تلگرم ممکن است چنین کلاینتی را محدود کند. مسئولیتش با خودتان است.

## 🔄 آپدیت خودکار

آپدیت خودکار عمداً **غیرفعال** شده (`-D DESKTOP_APP_DISABLE_AUTOUPDATE=ON`)؛ چون در غیر این صورت تلگرام خودش را با نسخهٔ رسمی جایگزین می‌کرد و محدودیت ۳ حساب برمی‌گشت. برای نسخهٔ جدید کافی است ورک‌فلو را دوباره اجرا کنید.

## 🧩 جزئیات فنی بیلد

- **رانر:** `windows-latest` (ویندوز سرور با Visual Studio و Windows SDK از پیش نصب)
- **منبع:** کلونِ سطح‌اول (shallow) از `dev` رسمی با همهٔ ساب‌مدیول‌ها
- **کتابخانه‌ها:** `Telegram/build/prepare/prepare.py` مسیر win64 (Qt 6، OpenSSL 3، FFmpeg، tg_owt، ...) — هر دو پیکربندی Debug و Release ساخته می‌شوند تا لینکِ Release درست کار کند
- **بیلد:** `configure.bat x64` + `cmake --build out --config Release`
- **کش:** پوشهٔ `Libraries` (جدا برای Qt) و `ThirdParty` با کلید مبتنی بر هشِ اسکریپت prepare + شمارهٔ هفته
- دستور بیلد برگرفته از ورک‌فلوی آزمودهٔ [64Gram](https://github.com/TDesktop-x64/tdesktop/blob/dev/.github/workflows/win.yml) است که برای سورسِ رسمی (به‌جای فورک) تطبیق داده شده.
